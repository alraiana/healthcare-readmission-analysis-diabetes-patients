# Predicting-30-Day-Hospital-Readmissions-Among-Patients-With-Diabetes
Using UCI Diabetes 130-US Hospitals dataset to determine what patient and hospitalization characteristics are associated with 30-day hospital readmission, and if we use those characteristics to identify patients at elevated risk

# Project Overview
This project analyzes hospital encounters involving patients with diabetes to investigate factors associated with 30-day hospital readmission.

The project combines healthcare data analysis, statistical exploration, machine learning, and interactive data visualization using Python and Microsoft Power BI.

# Research Question
What patient and hospitalization characteristics are associated with 30-day hospital readmission, and can these characteristics be used to identify patients at elevated risk?

# Objectives
- Clean and prepare healthcare encounter data for analysis
- Explore demographic, clinical, and utilization characteristics
- Analyze factors associated with hospital readmission
- Develop and evaluate predictive models for 30-day readmission
- Build an interactive Power BI dashboard
- Communicate findings through clear healthcare-focused visualizations

# Dataset
The primary dataset is the [UCI Diabetes 130-US Hospitals for Years 1999-2008 dataset]([url](https://archive.ics.uci.edu/dataset/296/diabetes+130-us+hospitals+for+years+1999-2008)). The dataset contains hospital encounter information for patients with diabetes and includes a readmission outcome.

# Analysis
The project will examine: 30-day readmission rates, patient demographics, hospital utilization, length of stay, admission and discharge characteristics, diagnosis categories, medication-related variables and relationships between patient characteristics and readmission.

# Machine Learning
Predictive modeling will be used to investigate whether patient and hospitalization characteristics can identify encounters associated with 30-day readmission.

Models will be evaluated using metrics including: precision, recall, F1-score and ROC-AUC

# Power BI Dashboard
An interactive Power BI dashboard will provide an overview of: readmission rates, patient demographics, hospital utilization, length of stay, readmission-related factors and model-related insights.

Dashboard screenshots will be added to this repository as the project progresses.

# Tools & Technologies
Python, pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook, Microsoft Power BI, Git and GitHub

# Important Note
This project is intended for educational and portfolio purposes. The analysis describes associations observed in the dataset and should not be interpreted as clinical guidance or evidence of causation.
